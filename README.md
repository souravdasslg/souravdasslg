- 📚 **Two books shaped how I think:** *Atomic Habits* for systems over goals, and Parag Parikh's *Value Investing and Behavioral Finance* for staying rational with money.
- ✈️ **Solo travel is how I reset.** Bangalore in 2007, Meghalaya in 2022 — the next one is always on the list.
